# @toneflix/studio-timeline

The multitrack editor of [Toneflix Studio](https://toneflix.github.io/studio/). Drag, split, trim, fade and layer clips across tracks, with snapping and undo, in any web app.

```sh
pnpm add @toneflix/studio-timeline
```

```ts
import { StudioTimeline } from '@toneflix/studio-timeline';
```

It is one part of Toneflix Studio. Install [`@toneflix/studio`](https://www.npmjs.com/package/@toneflix/studio) to get every part from one import. See [Packages](https://toneflix.github.io/studio/guide/packages) for what each package does.
