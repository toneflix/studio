# @toneflix/studio-waveforms

Waveforms for [Toneflix Studio](https://toneflix.github.io/studio/): peaks are worked out in a Web Worker, cached on the device, and drawn on a canvas at any zoom.

```sh
pnpm add @toneflix/studio-waveforms
```

```ts
import { Waveforms, drawWaveform } from '@toneflix/studio-waveforms';
```

It is one part of Toneflix Studio. Install [`@toneflix/studio`](https://www.npmjs.com/package/@toneflix/studio) to get every part from one import. See [Packages](https://toneflix.github.io/studio/guide/packages) for what each package does.
